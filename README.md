# Daily Thrive OS

Build a modern, dark-mode mobile web app for a personal Athletic & Recovery OS.

TOP HEADER: Daily readiness score card with quick sliders for Sleep Hours (0-12), Energy Level (1-10), and Body Weight (kg/lbs).

MAIN CARDS (4 Quick-Action Action Tabs):

🏊 Swim: Form to log stroke, total meters, pace per 100m, and split times.

🏋️ Gym: Form to log exercise name, sets, reps, weight, and muscle group.

🥗 Fuel: Form to log meal type, calories, and protein grams.

😴 Recovery: Form to log sleep duration, sleep quality, and notes.

BOTTOM SECTION: Daily timeline feed showing entries logged today.

STYLE: Glassmorphism dark mode with high contrast buttons, optimized for quick one-handed mobile input."*
